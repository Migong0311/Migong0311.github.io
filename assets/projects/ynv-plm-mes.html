밸브 제조업체 와이엔브이(주)의 PLM과 MES 유지보수를 담당하고 있습니다. 영업·기술연구·생산 부서에서 의뢰하는 문제를 확인하고, 조회·계산·저장·출력과 시스템 간 데이터 연계를 수정합니다.

01비활성화된 승인도 버튼에서 PLM 결재자 정보까지 역추적SR2610-0001 · MES 등록 · 2026.09.30 · 완료
문제

견적·수주 상세에서 승인도는 출력되지만, 승인도 확인 버튼은 활성화되지 않았습니다.

원인·맥락

MES는 PLM 결재자가 NULL이면 버튼을 비활성화하도록 되어 있었습니다. PLM 승인도 생성 메서드의 하드코딩된 사번이 변경된 사번과 맞지 않아 결재자 조회 결과가 NULL이 되는 상황이 확인됐습니다.

수정 내용

변경된 사번을 조회 파라미터에 반영하고, 이미 결재자 정보가 NULL로 저장된 데이터는 DB에 보완했습니다.

화면 버튼만 강제로 활성화하지 않고, 연결된 시스템의 원천 데이터까지 따라가 문제를 수정한 사례입니다.
